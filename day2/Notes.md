Datatypes

    - Primitive Datatype
    - Non Primitive Datatypes

# Primitive Datatypes

    - String    '' and  " "
    - Number    Integer  and floating point
    - BigInt    very large int value
    - Boolean   true or false
    - Undefined variable is created but no value is assigned    let y ;
    - Null       empty or null            ex :  let x  = null
    - Symbol      unique identifier         ex :  symbol("id")

# Non Primitive Datatypes

    - Object  stores key value pair
      let book = {
        name : "Head first java",
        pages : 1002
      }
      book.name  objectref.attribute
    - Array
      let names = ["Aayush","Goku","Luffy","Naruto"]
    - Function
    - Date

### How to check datatype of a variable Ans : typeof variable
